Создай необходимые файлы для приложения сообщений на Django 6. Обрати внимание что модель данных уже создана в постгрес (файл messages.sql) он является решеренсом. План использовать модели джанго manage=true с runsql тригерами. тригеры должны примениться миграцией, обрати внимание что есть тригеры для этого приложения сообщения а есть общие для всего джанго проекта которые нужно положить для всех
витрины данных переделай на джанговский стиль они относятся к бизнес логике
посмотри файл prompt.txt в нем приблизительная структура файлов для приложения сообщений, главно модель, дальше запросы (видимо это те витрины что есть перенесенные на питон) админка с возможностью редактировать то что не запрещено базой и апи на Django Rest Framework (полный цикл crud учитывая специфику модели данных)
мне важна чистота модели данных, не меняй ее принципиально относительно постгрес кода
проверь насколько хорошо создана модель
оформление русский нейтральный, без формулировок мы делаем с прелюдиями в каждом файле и докстрингами
пример код модели
сгенерируй все файлы согласно плану и те что считаешь нужными
используй лучшие джанго и питон практики
